# 🎨 [FE-005] Восстановление прогресса и отображение оценки при повторном открытии урока

> **Приоритет:** Medium (P1)  
> **Связанные задачи:** BE-005, QA-005  
> **Компоненты / Страницы:** `frontend/src/app/lessons/[id]/page.tsx`, `frontend/src/components/player/PuckLessonViewer.tsx`

## 🎯 Цель задачи
Устранить баг потери контекста: сейчас при открытии уже завершенного урока студент видит пустые поля ввода и кнопку «Завершить урок», словно он попал сюда впервые. Необходимо запрашивать прогресс урока, отображать статус «Пройден», показывать набранный балл и фидбек преподавателя.

## 🖥 Пользовательский интерфейс (UI / UX)
- **Хедер плеера урока (`/lessons/[id]`):**
  - Если урок пройден:
    - Зеленый бейдж: `✓ Урок пройден • Оценка: 95%`.
    - Кнопка в хедере: «Пройти заново» (вместо повторной отправки «Завершить урок»).
- **Баннер результатов (Result Banner):**
  - В верхней части урока отображать карточку с итогами:
    - Набранный балл.
    - Дата завершения.
    - Если есть проверенное эссе: комментарий учителя (зеленая плашка с цитатой преподавателя) и начисленные баллы.
- **Интерактивные тесты:**
  - Если урок уже сдан, переводить блоки в режим «Просмотр решения» (показывать правильные ответы или предыдущий выбор студента), либо оставлять возможность интерактивной тренировки по кнопке «Тренироваться снова».

## 🔌 Интеграция с API (Контракт с Бэкендом)
- При маунте страницы `useEffect`:
  ```typescript
  const [progress, setProgress] = useState<any>(null);
  
  useEffect(() => {
    const init = async () => {
      const [lessonRes, progressRes] = await Promise.all([
        api.get(`/lessons/${id}`),
        api.get(`/lessons/${id}/progress`).catch(() => null),
      ]);
      setLessonData(lessonRes.data.data?.lesson || lessonRes.data);
      if (progressRes?.data?.status === 'completed') {
        setIsCompleted(true);
        setProgress(progressRes.data);
      }
    };
    init();
  }, [id]);
  ```

## ✅ Критерии приёмки (Definition of Done)

- [x] Отображается набранный балл и комментарий преподавателя за ДЗ.
- [x] Исключена случайная повторная отправка пустого результата.
