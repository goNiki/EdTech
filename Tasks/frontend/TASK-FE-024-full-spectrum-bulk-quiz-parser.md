## 🎯 Цель задачи
Обеспечить возможность массового импорта из текста (Word, PDF, блокноты) для **всех 8 типов интерактивных блоков**, зарегистрированных в конфигурации редактора уроков Puck:
1. `QuizSingleBlock` (Один правильный ответ)
2. `QuizMultiBlock` (Несколько правильных ответов)
3. `QuizMatchBlock` (Сопоставление пар в 2 колонки)
4. `QuizDropdownBlankBlock` (Текст с выпадающими списками вариантов)
5. `QuizInputBlankBlock` (Текст с пропусками для ручного ввода)
6. `QuizSequenceBlock` (Хронологическая последовательность / порядок)
7. `QuizEssayBlock` (Развернутый ответ / Эссе с рубрикой оценивания)
8. `FileUploadBlock` (Практическое задание с загрузкой файла решения)

В текущей версии реализован импорт только первых 2 типов (single и multi). Преподавателям приходится вручную добавлять остальные 6 блоков, что сводит на нет ценность быстрого импорта объемных учебных программ.

## 📝 Спецификация синтаксиса и парсера (`quiz-parser.ts`)

### 1. Единый DSL для текстового распознавания
Парсер определяет тип блока либо по явному префиксу тега `[TYPE]`, либо по эвристике содержимого блока:

```text
=====================================================
1. ОДИН ВЫБОР (Single Choice)
=====================================================
[SINGLE]
Какая архитектура изолирует доменную логику?
A. Active Record
B. Clean Architecture *
C. Monolithic Core
ANSWER: B

=====================================================
2. МНОЖЕСТВЕННЫЙ ВЫБОР (Multiple Choice)
=====================================================
[MULTI]
Выберите протоколы прикладного уровня:
[x] HTTP/2
[x] gRPC
[ ] TCP
[x] WebSockets

=====================================================
3. СОПОСТАВЛЕНИЕ ПАР (Matching)
=====================================================
[MATCH]
Сопоставьте шаблоны и их определения:
AST Tree :: Иерархическое дерево блоков
Block Props :: Параметры компонентов
Puck Canvas :: Область визуального рендеринга
POINTS: 15

=====================================================
4. ПРОПУСКИ СО СПИСКОМ (Dropdown)
=====================================================
[DROPDOWN]
Заполните пропуски в предложении:
Спецификация для REST API называется {OpenAPI; Buf, WSDL}, а для RPC систем чаще всего используется {gRPC; GraphQL, SOAP}.
POINTS: 10

=====================================================
5. ПРОПУСКИ С РУЧНЫМ ВВОДОМ (Input Blank)
=====================================================
[INPUT]
Вставьте точные термины:
Команда для переключения веток в Git: git [checkout]. Для отката изменений используется git [reset].
POINTS: 10

=====================================================
6. ПОСЛЕДОВАТЕЛЬНОСТЬ (Sequence)
=====================================================
[SEQUENCE]
Расставьте этапы обработки запроса в правильном порядке:
-> Прием HTTP запроса роутером
-> Валидация JWT токена в Middleware
-> Вызов бизнес-логики в сервисе
-> Запись в БД и отправка JSON ответа
POINTS: 15

=====================================================
7. РАЗВЕРНУТЫЙ ОТВЕТ (Essay)
=====================================================
[ESSAY]
Опишите преимущества применения Чистой Архитектуры в микросервисах:
РУБРИКА: Полнота ответа, понимание инверсии зависимостей, тестопригодность.
ОТВЕТ: Независимость от фреймворков и БД, легкое написание unit-тестов.
POINTS: 25

=====================================================
8. ПРАКТИЧЕСКАЯ РАБОТА С ФАЙЛОМ (File Upload)
=====================================================
[FILE]
Лабораторная работа: Реализация роутинга на Chi
ИНСТРУКЦИЯ: Прикрепите архив с кодом (.zip) или PDF отчет с листингом.
ФОРМАТЫ: .zip, .tar.gz, .pdf, .go
ЛИМИТ: 25
POINTS: 50
```

## 🔌 Маппинг распознанных данных в блоки Puck (`convertQuizzesToPuckBlocks`)

| Тип в парсере | Puck Block Type | Формируемые Props |
| :--- | :--- | :--- |
| `single` | `QuizSingleBlock` | `id`, `question`, `points`, `options: [{ text, isCorrect: "true"/"false", explain }]` |
| `multi` | `QuizMultiBlock` | `id`, `question`, `points`, `options: [{ text, isCorrect: "true"/"false" }]` |
| `match` | `QuizMatchBlock` | `id`, `question`, `points`, `pairs: [{ left, right }]` |
| `dropdown` | `QuizDropdownBlankBlock` | `id`, `question`, `points`, `templateText` |
| `input` | `QuizInputBlankBlock` | `id`, `question`, `points`, `templateText` |
| `sequence` | `QuizSequenceBlock` | `id`, `question`, `points`, `items: [{ text }]` |
| `essay` | `QuizEssayBlock` | `id`, `question`, `points`, `rubric`, `sampleAnswer` |
| `file` | `FileUploadBlock` | `id`, `title`, `instructions`, `points`, `allowedTypes`, `maxSizeMB` |

Каждый сгенерированный блок обязан содержать уникальный `id` вида `${BlockType}-${Date.now()}-${idx}-${rnd}`.
