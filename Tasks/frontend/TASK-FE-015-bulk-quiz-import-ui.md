# 🎨 [FE-015] Модальное окно быстрого текстового импорта тестов (Bulk Quiz Import) в Puck Editor

> **Приоритет:** High (P0)  
> **Связанные задачи:** BE-015, QA-015  
> **Компоненты / Страницы:** `frontend/src/app/teacher/lessons/[id]/edit/page.tsx`, `frontend/src/lib/puck-config.tsx`, `frontend/src/components/editor/`

## 🎯 Цель задачи
Устранить самую утомительную рутину авторов курсов — ручное создание десятков тестов по одному вопросу через клики мышью. Создать модальное окно «⚡ Быстрый импорт тестов», позволяющее вставить сырой текст (из Word, блокнота или мессенджера) в привычных форматах (Aiken, GIFT, нумерованные списки с галочками/звездочками), на лету распарсить его в интерактивные блоки Puck Editor и добавить в урок в 1 клик.

## 🖥 Пользовательский интерфейс (UI / UX)
- **Точка входа:**
  - В шапке конструктора урока `/teacher/lessons/[id]/edit` добавить заметную кнопку:  
    `[ ⚡ Быстрый импорт тестов ]` (с иконкой молнии или файла с вопросами).
- **Двухоконное модальное окно (Split View Modal):**
  - **Левая колонка (Ввод текста):**
    - Многострочное текстовое поле с удобным шрифтом (моноширинный или читаемый sans).
    - Кнопка *«Вставить пример шаблона»* (подставляет готовый образец для ориентира).
    - Кнопка *«Загрузить из .docx / .txt»* (чтение текста напрямую из файла).
    - Справка по форматам в виде подсказки (tooltip).
  - **Правая колонка (Live Preview):**
    - В реальном времени (debounce 150 мс) отображает список распознанных тестов:
      - Бейдж типа: `Одиночный выбор (Single)` или `Множественный выбор (Multi)`.
      - Текст вопроса.
      - Варианты ответов с зеленой подсветкой правильного варианта.
      - Счетчик: *«Распознано вопросов: 15»*.
      - Предупреждения: *«Вопрос #4: не указан правильный ответ (пометьте * или [x])»*.
  - **Подвал модалки:**
    - Кнопки: «Отмена» и «Добавить 15 тестов в урок» (активна, только если распознан хотя бы 1 валидный тест).

## 🔌 Техническая реализация и парсер
Создать утилиту `frontend/src/lib/quiz-parser.ts`:
1. Поддержка форматов:
   - **Формат 1 (со звездочкой):**
     ```text
     1. Вопрос?
     a) Вариант 1
     b) Вариант 2 *
     c) Вариант 3
     ```
   - **Формат 2 (Markdown checkboxes):**
     ```text
     2. Выберите верные утверждения:
     [x] Верный вариант А
     [ ] Неверный вариант Б
     [x] Верный вариант В
     ```
   - **Формат 3 (Aiken / Moodle):**
     ```text
     3. Какая столица Италии?
     A. Мадрид
     B. Рим
     C. Берлин
     ANSWER: B
     ```
2. Генерация блоков Puck:
   - Для каждого вопроса создается объект блока:
     - Одиночный: `{ type: 'SingleChoiceBlock', props: { id: generateId(), question, options, points: 5 } }`
     - Множественный: `{ type: 'MultipleChoiceBlock', props: { id: generateId(), question, options, points: 10 } }`
3. Вставка в состояние:
   - Добавление массива новых блоков в конец списка `appState.data.content` через Puck dispatch.
