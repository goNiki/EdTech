# 🎨 [FE-011] Модальное окно и скачивание сертификата об окончании курса

> **Приоритет:** Low (P2)  
> **Связанные задачи:** BE-011, QA-011  
> **Компоненты / Страницы:** `frontend/src/app/dashboard/courses/[id]/page.tsx`, `frontend/src/app/certificates/[code]/page.tsx`

## 🎯 Цель задачи
Предоставить студенту праздничный опыт завершения курса: при достижении 100% прогресса показывать кнопку «Получить сертификат» с золотой иконкой, открывать модальное окно с красивым дизайнерским дипломом, возможностью печати/скачивания и публичной страницей проверки.

## 🖥 Пользовательский интерфейс (UI / UX)
- **Учебный кабинет курса (`/dashboard/courses/[id]`):**
  - При `completion_percentage === 100`:
    - Баннер с конфетти: *«Поздравляем! Вы успешно завершили курс!»*.
    - Кнопка «Посмотреть сертификат» (золотой/градиентный фон с иконкой `Award`).
- **Модальное окно сертификата (Certificate Modal):**
  - Оформление в стиле официального диплома:
    - Логотип платформы ED.Learn.
    - Имя и фамилия студента.
    - Название курса.
    - Итоговый средний балл (например, 96%).
    - Уникальный идентификатор `EDL-2026-AB12CD` и QR-код со ссылкой на страницу верификации.
    - Кнопка «Печать / Сохранить в PDF» (`window.print()`).
    - Кнопка «Копировать ссылку для LinkedIn / резюме».
- **Публичная страница верификации (`/certificates/[code]`):**
  - Доступна для всех без входа в аккаунт, подтверждает подлинность выданного документа.

## 🔌 Интеграция с API (Контракт с Бэкендом)
- Запрос сертификата: `GET /api/v1/courses/${id}/certificate`
- Верификация: `GET /api/v1/certificates/verify/${code}`

## ✅ Критерии приёмки (Definition of Done)
- [x] Кнопка сертификата появляется строго при 100% прохождении курса.
- [x] Сертификат форматируется для корректной печати в альбомной ориентации (A4 landscape).
- [x] Ссылка на верификацию открывает публичную карточку подтверждения.
