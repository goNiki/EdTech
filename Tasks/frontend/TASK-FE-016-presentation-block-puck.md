# 🎨 [FE-016] Разработка блока презентаций (PresentationBlock) в Puck Editor и плеере уроков

> **Приоритет:** Medium (P1)  
> **Связанные задачи:** BE-016, QA-016  
> **Компоненты / Страницы:** `frontend/src/lib/puck-config.tsx`, `frontend/src/components/player/PuckLessonViewer.tsx`, `frontend/src/components/editor/CustomOutline.tsx`

## 🎯 Цель задачи
Добавить в конструктор Puck Editor и интерактивный плеер уроков полноценный блок презентаций (`PresentationBlock`). Блок должен поддерживать два режима:
1. **Встраивание по ссылке (Embed Mode):** Google Презентации (Google Slides), Canva, Speaker Deck, Office 365.
2. **Загрузка PDF-файла (PDF Mode):** слайдер PDF-документа с перелистыванием страниц и полноэкранным режимом.

## 🖥 Пользовательский интерфейс (UI / UX)
- **В редакторе Puck (`puck-config.tsx`):**
  - Добавить блок `PresentationBlock` в категорию «Медиа и презентации» (иконка монитора/проектора `Presentation` из Lucide).
  - Панель настроек блока (Props):
    - `title` (текст): Название презентации.
    - `mode` (селект): `embed` («Ссылка на Google Slides / Canva») или `pdf` («Загрузка PDF-файла»).
    - `embedUrl` (URL): ссылка на внешнюю презентацию.
    - `pdfUrl` (файл/URL): загрузка PDF через файловый пикер.
    - `aspectRatio` (селект): `16:9` (стандарт) или `4:3`.
    - `allowDownload` (чекбокс): разрешить ли студентам скачивание оригинального файла.
- **В интерактивном плеере (`PuckLessonViewer.tsx`):**
  - **Для режима Embed:**
    - Адаптивный контейнер с сохранением пропорций 16:9.
    - Встроенный iframe с автоматической нормализацией ссылок (для Google Slides замена `/edit` на `/embed`).
    - Кнопка «Во весь экран» (Fullscreen API).
  - **Для режима PDF:**
    - Встроенный вьюер презентации с навигацией по слайдам:
      - Кнопки «‹ Предыдущий» и «Следующий ›» (поддержка стрелок на клавиатуре).
      - Номер текущего слайда: `Слайд 4 из 28`.
      - Кнопка разворачивания на весь экран.
      - Кнопка «Скачать презентацию» (если разрешено автором).

## 🔌 Интеграция с API (Контракт с Бэкендом)
- Загрузка PDF презентации: `POST /api/v1/upload` (с `category = presentation`).
- Сохранение параметров презентации в структуре JSON урока в `lesson.content`.
