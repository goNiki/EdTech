# 🎨 [FE-009] Адаптация плеера уроков под серверную проверку квизов

> **Статус:** ✅ Completed  
> **Приоритет:** Medium (P1)  
> **Связанные задачи:** BE-009, QA-009  
> **Компоненты / Страницы:** `frontend/src/components/player/PuckLessonViewer.tsx`, `frontend/src/app/lessons/[id]/page.tsx`

## 🎯 Цель задачи
Перевести интерактивный плеер `PuckLessonViewer` с локального расчета оценки на отправку структуры выбранных ответов на сервер, отображая результат проверки после подтверждения сервером.

## 🖥 Пользовательский интерфейс (UI / UX)
- Сохранена мгновенная интерактивность: студент выбирает варианты, сопоставляет пары, вводит текст в пропуски.
- При нажатии на «Проверить» / «Завершить урок»:
  - Отображается состояние загрузки «Проверка ответов на сервере...» с анимированным лоадером.
  - После ответа сервера правильные и ошибочные блоки подсвечиваются зеленым/красным цветом со специальными бейджами («Сервер: Верно / Неверно»).
  - В модальном окне итогов выводится подтвержденный сервером балл со значком защищенной серверной проверки.

## 🔌 Интеграция с API (Контракт с Бэкендом)
- При завершении урока собирается словарь ответов:
  ```typescript
  const completionPayload = {
    score: finalScore,
    answers: answersList,
    essays: submittedEssays,
  };
  const res = await api.post(`/lessons/${id}/complete`, completionPayload);
  ```
