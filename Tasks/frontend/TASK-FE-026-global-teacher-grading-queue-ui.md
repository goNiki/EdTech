> **Приоритет:** High (P1)  
> **Связанные задачи:** BE-027, QA-026  
> **Компоненты / Страницы:**

> - `frontend/src/components/teacher/PendingHomeworksQueue.tsx`

---

## 🎯 Цель задачи
Обновить страницу «Проверка заданий» (`/teacher/grading`) в левом главном меню, чтобы преподаватель видел реальную, полную картину всех требующих проверки работ по всем своим курсам.

Устранить проблему, когда выбор первого попавшегося курса с 0 работ блокировал видимость 4 непроверенных работ на курсе «Русский язык» (и других курсах автора).

---

## 🖥 Пользовательский интерфейс (UI / UX)

### 1. Фильтр по курсам (Course Filter Header)
- **Опция «Все курсы» по умолчанию:**
  - В выпадающем списке первым элементом должна стоять опция:
    `🌟 Все курсы (${totalPendingCount})`.
  - При открытии страницы по умолчанию выбраны «Все курсы».
- **Счетчики в селекторе курсов:**
  - Каждый пункт списка отображает название и бейдж/число непроверенных работ:
    - `Русский язык (4)`
    - `Основы Golang (0)`
  - Курсы с активными заданиями визуально выделяются или располагаются в начале списка.
- **Быстрые бейджи-фильтры (Quick Filter Pills):**
  - Под заголовком или рядом с селектором разместить компактные кнопки-таблетки для мгновенного переключения между курсами с ненулевым количеством заданий.

### 2. Карточка задания в общей очереди (`PendingHomeworksQueue.tsx`)
- В каждой карточке задания добавить бейдж с названием курса:
  - Например, яркий бейдж `[Русский язык]` рядом с `[Урок: Синтаксис]`.
  - При клике на бейдж курса — быстрая фильтрация очереди только по этому курсу.
- Индикатор давности сдачи (относительное время: «2 часа назад», «Вчера», «3 дня назад») с цветовым акцентом (красный бейдж, если работа ждет проверки более 48 часов).
- Информация о студенте (ФИО, email, аватар) и формулировка задания.

### 3. Интерактивная проверка и обновление очереди
- При нажатии «Проверить работу» открывается модальное окно `ModalGradeHW`.
- После выставления оценки и нажатия «Сохранить оценку»:
  - Модальное окно закрывается.
  - Показывается всплывающий тост: «Оценка успешно выставлена (+X баллов)».
  - Проверенная работа плавно исчезает из списка (локальный оптимистичный апдейт).
  - Счетчики в селекторе курсов и общем заголовке декрементируются на 1 без полной перезагрузки страницы.

## 🔌 Интеграция с API (Контракт с Бэкендом BE-027)

- **Основной запрос:**
  `GET /api/v1/teacher/grading/pending`
  - Если выбран конкретный курс: `GET /api/v1/teacher/grading/pending?course_id=${selectedCourseId}`
- **Маппинг ответа:**
  - `data.items` ➔ передается в `<PendingHomeworksQueue items={items} />`.
  - `data.total` ➔ отображается в заголовке страницы: «Очередь на проверку (Всего: ${total})».
  - `data.courses_summary` ➔ формирует пункты селектора курсов со счетчиками.
