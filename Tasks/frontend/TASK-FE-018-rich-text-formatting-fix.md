## 1. Описание проблемы (Problem Statement)
В редакторе Puck при работе с текстовыми блоками:
* **«Текстовый блок (Canvas)»** (`RichTextCanvasEditor`)
* **«Лекция / Статья (Word)»** (`RichTextWordEditor`)
невозможно применить форматирование (жирный, курсив, заголовки, размер шрифта, шрифт, цвет) к выделенным фрагментам текста. Работало только выравнивание (влево, по центру, вправо).
При выделении слова или предложения и клике на любую кнопку форматирования панели инструментов стиль не применялся к выделению.

---

## 2. Анализ причин (Root Cause Analysis)
1. **Перехват фокуса на событии `pointerdown`:**
   В современных браузерах (Chromium / WebKit) события Pointer Events срабатывают до Mouse Events (`pointerdown` -> `mousedown` -> `click`).
   На кнопках тулбара и контейнере риббона стоял `e.preventDefault()` только на `onMouseDown`.
   При клике мышью `pointerdown` перехватывал фокус с `contentEditable` на кнопку тулбара, в результате чего выделение (`window.getSelection()`) сбрасывалось браузером ещё до вызова `execCommand`.
2. **Сброс сохранённого `Range` при вызове `.focus()`:**
   В функции `restoreSelection()` вызывался `editorRef.current.focus()`. В ряде браузеров программный `.focus()` на `contentEditable` div сбрасывает активный Range в начало или конец блока, после чего команда форматирования применяется к пустому курсору вместо выделенного фрагмента.
3. **Сохранение схлопнутого Range в `selectionchange`:**
   Обработчик `selectionchange` перезаписывал сохраненный диапазон даже когда `range.collapsed === true` в момент клика по кнопкам панели.
4. **Неэффективность устаревших тегов при `styleWithCSS` и конфликт с Tailwind Typography (`prose`):**
   При вызове `formatBlock` или шрифтов необходимо надежно оборачивать выделенный текст или применять стандартные теги `<strong>`, `<em>`, `<u>`, `<mark>`, заголовки `<h2>`, `<h3>` и inline-стили.

---

## 3. Критерии приёмки (Definition of Done)
1. [x] В `RichTextCanvasEditor` и `RichTextWordEditor`:
   - Кнопки тулбара имеют `preventBtnFocus` с `onPointerDown={(e) => { e.preventDefault(); e.stopPropagation(); }}` и `onMouseDown={(e) => { e.preventDefault(); e.stopPropagation(); }}`.
   - Выделенный фрагмент текста не теряет фокус при кликах по кнопкам тулбара.
   - Успешно применяются:
     - Жирный (Bold / `<strong>` / `styleWithCSS: false`)
     - Курсив (Italic / `<em>`)
     - Подчёркивание (Underline / `<u>`)
     - Зачёркнутый (Strikethrough / `<s>`)
     - Моноширинный код (`<code>` для выделения, `<pre>` для блока)
     - Заголовки (H1, H2, H3, P)
     - Шрифты (Sans, Serif, Mono) и размеры текста (13px, 16px, 22px) через `applyInlineStyle`
     - Маркер / Выделитель цвета
     - Списки (маркированный, нумерованный)
     - Очистка форматирования
2. [x] Изменения форматирования мгновенно сохраняются в модель урока (`contentHtml`) и обновляют состояние Puck.
3. [x] Успешная сборка проекта `npm run build` с нулевым кодом ошибки.
