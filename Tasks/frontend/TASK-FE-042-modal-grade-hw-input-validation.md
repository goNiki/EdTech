## 🎯 Описание задачи (UI / UX Improvement)
В модальном окне `ModalGradeHW` преподаватель может ввести число больше `max_points` или меньше `0`. 
Хотя стандартные HTML5-атрибуты `min={0}` и `max={hw.max_points}` присутствуют на теге `<input>`, в интерфейсе отсутствуют:
1. Визуальная подсветка ошибки (красная рамка вокруг поля ввода).
2. Явное текстовое сообщение под полем: «Балл не может превышать %d» или «Балл не может быть отрицательным».
3. Динамическая блокировка кнопки «Утвердить оценку» при некорректно введенном значении.

---

## 🔬 Шаги воспроизведения
1. Войти под преподавателем и перейти на `/teacher/grading`.
2. Нажать «Проверить работу».
3. Ввести в поле балла значение `30` при максимуме `25`.
4. Нажать кнопку отправки.

### Фактический результат
Поле не меняет цвет рамки на красный в реальном времени при вводе невалидного значения, кнопка отправки активна.

### Ожидаемый результат
- При вводе значения `> max_points` или `< 0`:
  - Поле ввода получает класс `border-rose-500 focus:ring-rose-500 text-rose-600`.
  - Под полем отображается подсказка цвета `text-rose-500`: «Балл не может превышать X».
  - Кнопка «Утвердить оценку» отключается (`disabled`).
