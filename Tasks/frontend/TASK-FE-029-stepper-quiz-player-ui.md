## 🎯 Цель задачи
Реализовать современный пошаговый режим прохождения тестирования (**«1 вопрос на экран» / Stepper Wizard**) в точном соответствии с макетом дизайна пользователя:
- Верхняя полоса статуса: логотип платформы, бейдж типа («Контрольный тест»), индикатор времени (таймер).
- Карточка вопроса: подзаголовок «Вопрос X из Y», бейдж стоимости «10 баллов», крупный текст вопроса.
- Варианты ответов: элегантные кликабельные радиокнопки/чекбоксы со скруглением, подсветкой выбранного варианта зеленым/индиго контуром.
- Нижняя панель навигации: кнопки «← Назад» и «Следующий вопрос →» (акцентная синяя/фиолетовая кнопка). На последнем вопросе — «Завершить тест».
- Плитка быстрой навигации по номерам вопросов `[1][2][3]...[N]` с индикацией состояния (решен, текущий, пропущен).

## 🖥 Пользовательский интерфейс (UI / UX)

### 1. Переключение режимов отображения в уроке
- В свойствах урока поддерживать `test_layout`:
  - `'stepper'` — пошаговый визард (1 вопрос на экран). Включается по умолчанию для уроков с типом `test` (Контрольный тест).
  - `'scroll'` — сплошная вертикальная лента (классический лонгрид).
- Для уроков смешанного типа (лекция + тест): если есть теоретические блоки (`HeaderBlock`, `RichTextBlock`), они показываются первым вводным шагом, после чего студент переходит к шагам с вопросами.

### 2. Структура экрана Stepper Player (`QuizStepperPlayer.tsx`)
```text
+-------------------------------------------------------------------------+
| [ED.Learn]  [Контрольный тест]                            (⏱ 14:20)     |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ Линейка прогресса: ====================>                           ] |
|  [ Плитка вопросов: (1✓) (2 текущий) (3) (4) (5)                      ] |
|                                                                         |
|  +-------------------------------------------------------------------+  |
|  | Вопрос 2 из 10                                          10 баллов |  |
|  |                                                                   |  |
|  | На какие вопросы отвечает глагол в неопределённой форме?          |  |
|  |                                                                   |  |
|  |  ( )  Кто? Что?                                                   |  |
|  |  (●)  Какой? Какая? Какое? [Выбран - зеленая обводка]             |  |
|  |  ( )  Что делать? Что сделать?                                    |  |
|  |  ( )  Где? Когда?                                                 |  |
|  |                                                                   |  |
|  +-------------------------------------------------------------------+  |
|                                                                         |
|  [← Назад]                                    [Следующий вопрос →]      |
+-------------------------------------------------------------------------+
```

### 3. Интерактивные состояния
- **Выбор ответа:**
  - Клик по всей области плашки варианта выбирает его.
  - Активный вариант выделяется фирменной обводкой (`border-indigo-500` или `border-emerald-500`), мягким фоном и иконкой галочки.
- **Навигация:**
  - Кнопка «← Назад» неактивна на 1-м вопросе.
  - Кнопка «Следующий вопрос →» переключает на следующий шаг с плавной анимацией перехода (`fade` / `slide`).
  - На последнем вопросе правая кнопка меняет текст на:
    `[ Завершить тестирование ✓ ]` (акцентная зеленая или фиолетовая кнопка).
- **Плитка номеров вопросов:**
  - Размещается над карточкой вопроса (или в компактной выпадающей панели на мобильных устройствах).
  - Цветовая индикация:
    - Серый кружок: еще не просмотрен / не отвечен.
    - Синий/индиго кружок с кольцом: текущий активный вопрос.
    - Зеленый кружок с точкой: на вопрос дан ответ.
  - Клик по любому номеру позволяет мгновенно вернуться к любому вопросу для проверки.

## 🔌 Поддержка всех 8 типов блоков в Stepper
Компонент `QuizStepperPlayer` принимает блоки урока и адаптирует отображение под 1 вопрос:
1. `QuizSingleBlock` ➔ радио-список (в точности как на макете).
2. `QuizMultiBlock` ➔ чекбокс-список со счетчиком «Выберите один или несколько ответов».
3. `QuizMatchBlock` ➔ карточки сопоставления с интерактивным соединением пар кликом.
4. `QuizDropdownBlankBlock` ➔ текст с инлайн выпадающими списками.
5. `QuizInputBlankBlock` ➔ текст с аккуратными инпутами в пропусках.
6. `QuizSequenceBlock` ➔ карточки с перетаскиванием (drag-and-drop) или стрелками «Вверх / Вниз».
7. `QuizEssayBlock` ➔ текстовая область с подсчетом символов.
8. `FileUploadBlock` ➔ область Drag-and-Drop загрузки файла решения.
