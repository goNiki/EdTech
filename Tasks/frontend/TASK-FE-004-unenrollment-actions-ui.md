# 🎨 [FE-004] Интерфейс самоотчисления студента и исключения учащихся преподавателем

> **Приоритет:** High (P1)  
> **Связанные задачи:** BE-004, QA-004  
> **Компоненты / Страницы:** `frontend/src/app/dashboard/courses/[id]/page.tsx`, `frontend/src/components/teacher/StudentsTable.tsx`

## 🎯 Цель задачи
На бэкенде реализованы методы отчисления, однако во фронтенде полностью отсутствуют элементы управления для этих действий. Задача — добавить кнопку «Покинуть курс» в учебном кабинете студента и действие «Исключить студента» в таблице учащихся преподавателя.

## 🖥 Пользовательский интерфейс (UI / UX)
- **Кабинет курса студента (`/dashboard/courses/[id]`):**
  - В сайдбаре или плашке информации о курсе добавить второстепенную кнопку: *«Покинуть курс»* (с иконкой выхода или корзины).
  - Модальное окно подтверждения (Confirm Dialog):
    - Заголовок: *«Вы уверены, что хотите покинуть курс?»*
    - Предупреждение: *«Ваш текущий прогресс будет сохранен, но курс исчезнет из списка активных.»*
    - Кнопки: «Отмена» и «Да, покинуть курс» (красная).
  - После подтверждения — вызов API, показ тоста и редирект в `/dashboard/courses`.
- **Таблица студентов преподавателя (`StudentsTable.tsx`):**
  - В колонку «Действия» рядом с кнопкой «Детальный отчет» добавить выпадающее меню действий или кнопку с иконкой крестика/удаления.
  - Модалка подтверждения: *«Исключить студента Иван Иванов из курса?»*
  - После успеха — удаление студента из таблицы и обновление общего счетчика учащихся.

## 🔌 Интеграция с API (Контракт с Бэкендом)
- Самоотчисление: `DELETE /api/v1/courses/${courseId}/enroll`
- Исключение преподавателем: `DELETE /api/v1/courses/${courseId}/students/${studentId}`

## ✅ Критерии приёмки (Definition of Done)
- [x] Студент может в 2 клика покинуть курс с обязательным подтверждением в диалоговом окне.
- [x] Преподаватель может удалить студента из списка курса.
- [x] После отчисления список курсов студента и таблица учителя моментально актуализируются.
