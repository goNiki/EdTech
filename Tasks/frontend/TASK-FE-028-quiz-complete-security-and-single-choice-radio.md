## 🎯 Цель задачи
1. **Устранить клиентский эксплойт с кнопкой «Завершить урок»:**
   В шапке плеера уроков (`LessonPlayer`) при наличии тестовых блоков убрать кнопку автоматического завершения со 100 баллами (`handleComplete()`). Завершение урока с тестами должно происходить **исключительно** через отправку формы ответов («Завершить тест и узнать результат»).
2. **Диалог подтверждения при досрочном выходе:**
   Если студент пытается покинуть урок (кнопка «← Назад» или закрытие) при наличии незавершенного теста, показывать предупреждающее модальное окно:
   *«Вы ответили только на X из Y вопросов. Завершить тестирование досрочно? Неотвеченные задания будут оценены в 0 баллов»*.
3. **Строгая Radio-семантика в блоке «Один ответ» (`QuizSingleBlock`) в Puck:**
   Исключить возможность выбора нескольких правильных ответов в блоке одиночного выбора. При отметке любого варианта как правильного (`isCorrect = true`) все остальные варианты в блоке должны автоматически становиться `false`. Добавить валидацию перед сохранением урока.

## 🔍 Текущее состояние кода
1. В `frontend/src/app/lessons/[id]/page.tsx` (строка 151):
   Кнопка в шапке вызывает `onClick={() => handleComplete()}` без аргументов. В функции `handleComplete` написано `score: payload?.score ?? 100`, что отправляет на бэкенд 100 баллов даже без прохождения теста.
2. В `frontend/src/lib/puck-config.tsx` (строка 621):
   При нажатии на «Сделать верным» в `QuizSingleBlock` вызывается:
   `updateNestedArrayItem('options', idx, 'isCorrect', isCorrect ? 'false' : 'true')`.
   Это независимый переключатель для каждого элемента массива, что позволяет автору выбрать 3 или 4 верных ответа в блоке одиночного выбора.

## 📝 Технические требования к реализации

### 1. Доработка плеера (`frontend/src/app/lessons/[id]/page.tsx`)
- Определять наличие квизов в уроке:
  `const hasQuizzes = blocks.some((b: any) => b.type?.startsWith('Quiz') || b.type === 'FileUploadBlock');`
- Если `hasQuizzes === true`:
  - В шапке **скрывать** кнопку «Завершить урок». Вместо нее показывать бейдж режима (например, `⚡ Контрольное тестирование`).
  - При нажатии на кнопку «← Назад» (`router.back()`):
    - Если тест еще не завершен (`!isCompleted`), открывать модальное окно `ConfirmExitQuizModal`.
    - В модалке две кнопки:
      - `[Продолжить тест]` — закрывает модалку, студент остается в тесте.
      - `[Завершить досрочно]` — отправляет текущие ответы на сервер с флагом `is_abandoned: true` и возвращает пользователя к курсу.
- Если `hasQuizzes === false` (обычная текстовая лекция):
  - Кнопка «Завершить урок» в шапке сохраняется и работает как фиксация прочтения.

### 2. Взаимоисключающий выбор (Radio) в `QuizSingleBlock` (`puck-config.tsx`)
- При клике на «Сделать верным» на Canvas:
  ```tsx
  onClick={(e) => {
    e.stopPropagation();
    selectThisBlock();
    // Обновляем весь массив options: у текущего idx ставим 'true', у всех остальных — 'false'
    const updatedOptions = options.map((opt: any, i: number) => ({
      ...opt,
      isCorrect: i === idx ? 'true' : 'false',
    }));
    updateProp('options', updatedOptions);
  }}
  ```
- В боковом инспекторе (Sidebar) `fields.options`:
  - Заменить независимый селект у каждого элемента на радио-выбор `correctOptionIndex` (или кастомное поле с радиокнопками), либо при изменении `isCorrect` в одном элементе автоматически сбрасывать остальные.
- **Валидация при сохранении урока:**
  - В редакторе уроков перед вызовом `handleSave` проверять все блоки `QuizSingleBlock`:
    - Если у блока ровно 0 правильных ответов — прерывать сохранение и выводить тост:
      *«В вопросе "${block.props.question}" не выбран ни один правильный ответ»*.
    - Если у блока > 1 правильного ответа — автоматически приводить к одному или выводить предупреждение.
