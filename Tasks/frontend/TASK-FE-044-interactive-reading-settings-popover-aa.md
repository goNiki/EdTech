## 🎯 Цель задачи
Предоставить каждому пользователю возможность персонализировать размер шрифта и комфорт чтения:
1. Изолировать масштабирование шрифта: увеличивать/уменьшать **строго обучающий контент** (текст лекций, задания, варианты ответов, пояснения, формулы, цитаты), **НЕ затрагивая** служебный каркас приложения (сайдбар, шапку, системные кнопки, иконки и тулбары).
2. Создать компактный выпадающий виджет настроек чтения **`Aa`** в верхней панели плеера уроков ([`/lessons/[id]`](../../frontend/src/app/lessons/%5Bid%5D/page.tsx)), работающий по аналогии с ридерами Apple Books, Medium, Telegram и Литрес.
3. Обеспечить сохранение выбранных параметров в `localStorage` (мгновенно без перезагрузки страницы) и фоновую синхронизацию с профилем пользователя на сервере (`PATCH /auth/preferences`).

## 🖥 Пользовательский интерфейс (UI / UX)

### 1. Кнопка и меню `Aa` в шапке плеера (`ReadingSettingsPopover.tsx`)
- В правой части шапки плеера размещается компактная кнопка с символом **`Aa`** и всплывающей подсказкой «Настройки чтения».
- При клике открывается всплывающее окно (Popover / Dropdown):
  - **Размер шрифта:**
    - Кнопки `A-` и `A+` и 4 визуальных деления:
      - `14px` (Компактный)
      - `16px` (Стандартный — по умолчанию)
      - `18px` (Комфортный)
      - `20px` (Крупный)
  - **Ширина страницы:**
    - Тумблер: `Стандартная (1024px)` / `Широкая (1280px+)`.
  - **Межстрочный интервал:**
    - Иконки `Стандартный (1.5)` / `Просторный (1.75)`.
  - **Цветовой фон чтения (опционально):**
    - Кружки выбора: Светлый / Сепия (мягкий бумажный `#FBF7EE`) / Темный.

### 2. Изоляция стилей (CSS Custom Properties)
Масштабирование применяется **только к контейнеру контента** через CSS-переменные:
```css
/* Применяется к контейнеру <main data-font-scale="..."> */
[data-font-scale="compact"] {
  --lesson-body-size: 0.875rem;   /* 14px */
  --lesson-lead-size: 1rem;       /* 16px */
}
[data-font-scale="medium"] {
  --lesson-body-size: 1rem;       /* 16px */
  --lesson-lead-size: 1.125rem;   /* 18px */
}
[data-font-scale="large"] {
  --lesson-body-size: 1.125rem;   /* 18px */
  --lesson-lead-size: 1.25rem;    /* 20px */
}
[data-font-scale="xlarge"] {
  --lesson-body-size: 1.25rem;    /* 20px */
  --lesson-lead-size: 1.375rem;   /* 22px */
}

/* Элементы контента наследуют переменную */
.lesson-content-area p,
.lesson-content-area li,
.lesson-content-area .prose {
  font-size: var(--lesson-body-size);
}
```
Служебные элементы (`Sidebar`, `TopNavbar`, кнопки `Завершить урок`, бейджи `text-[10px]`) остаются неизменными.
