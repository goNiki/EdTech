# 🎨 [FE-003] Транслитерация кириллицы при автогенерации URL-слага курса

> **Приоритет:** High (P0)  
> **Связанные задачи:** BE-003, QA-003  
> **Компоненты / Страницы:** `frontend/src/app/teacher/courses/new/page.tsx`, `frontend/src/app/teacher/courses/[id]/settings/page.tsx`, `frontend/src/lib/utils.ts`

## 🎯 Цель задачи
Исправить баг в мастере создания курса: при вводе названия на русском языке (например, *«Основы Golang для начинающих»*) регулярное выражение `/[^\w\s-]/g` полностью вырезает кириллические буквы, генерируя уродливый слаг с таймстампом (`course-1728000000000`) или обрезком из латинских слов (`golang`). Требуется внедрить полноценную функцию транслитерации ГОСТ/ISO для создания красивых SEO-friendly ссылок.

## 🖥 Пользовательский интерфейс (UI / UX)
- В поле «Название курса» при вводе текста в реальном времени заполняется поле «URL-слаг курса».
- Пример: *«Архитектура микросервисов и Go»* ➔ `arhitektura-mikroservisov-i-go`.
- Возможность ручной правки слага пользователем без затирания при дальнейшем наборе заголовка (флаг `isSlugManuallyEdited`).
- Валидация на лету: подсветка зеленым/красным допустимости символов.

## 🔌 Техническая реализация
- Добавить в `frontend/src/lib/utils.ts` функцию `transliterate(str: string): string`:
  - Таблица соответствий букв: `а: 'a', б: 'b', в: 'v', г: 'g', д: 'd', е: 'e', ё: 'yo', ж: 'zh', з: 'z', и: 'i', й: 'y', к: 'k', л: 'l', м: 'm', н: 'n', о: 'o', п: 'p', р: 'r', с: 's', т: 't', у: 'u', ф: 'f', х: 'h', ц: 'ts', ч: 'ch', ш: 'sh', щ: 'sch', ъ: '', ы: 'y', ь: '', э: 'e', ю: 'yu', я: 'ya'`.
- Очистка от знаков препинания и замена пробелов на одиночные дефисы:
  ```typescript
  export function slugify(text: string): string {
    return transliterate(text)
      .toLowerCase()
      .trim()
      .replace(/[^a-z0-9 -]/g, '')
      .replace(/\s+/g, '-')
      .replace(/-+/g, '-')
      .replace(/^-+|-+$/g, '');
  }
  ```

- [x] Знаки препинания (`!?,:;'"()`) удаляются без образования двойных дефисов.
- [x] Сохраняется возможность ручного ввода произвольного слага.
