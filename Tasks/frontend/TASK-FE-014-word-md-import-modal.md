# 🎨 [FE-014] Импорт текста из Word (.docx) и Markdown (.md) с сохранением форматирования в Puck Editor

> **Приоритет:** High (P1)  
> **Связанные задачи:** BE-014, QA-014  
> **Компоненты / Страницы:** `frontend/src/app/teacher/lessons/[id]/edit/page.tsx`, `frontend/src/components/editor/InlineEditable.tsx`, `frontend/src/lib/puck-config.tsx`

## 🎯 Цель задачи
Облегчить преподавателям перенос готовых учебных материалов (методичек, лекций, конспектов) в визуальный редактор. Реализовать импорт файлов `.docx` и `.md` с автоматической очисткой от мусорных офисных стилей, сохранением семантического форматирования (заголовки, списки, таблицы, полужирный/курсив) и вставкой в текстовый блок урока.

## 🖥 Пользовательский интерфейс (UI / UX)
- **Точки входа в импорт:**
  1. В тулбаре редактора `RichTextWordEditor` добавить кнопку с иконкой документа: *«Импорт .docx / .md»*.
  2. В шапке Puck Editor добавить кнопку быстрого действия: *«Вставить документ как блок»*.
  3. Поддержка Drag-and-Drop файла `.docx` / `.md` прямо на канвас текстового блока.
- **Диалоговое окно / Процесс импорта:**
  - При перетаскивании или выборе файла отображается индикатор: *«Конвертация документа...»*.
  - Если в `.docx` обнаружены картинки, отображать: *«Загрузка иллюстраций (3 из 5)...»*.
  - После конвертации текст вставляется в активный блок `WordText` или создается новый блок с готовым форматированием.
  - Показ тоста об успехе: *«Документ успешно импортирован (3 450 слов, 4 таблицы)»*.

## 🔌 Техническая реализация и интеграция
1. **Библиотеки:**
   - Установить `mammoth` (для парсинга `.docx` в чистый семантический HTML).
   - Установить `marked` (для парсинга `.md` в HTML).
2. **Парсинг Word (`.docx`):**
   ```typescript
   import mammoth from 'mammoth';

   const arrayBuffer = await file.arrayBuffer();
   const result = await mammoth.convertToHtml(
     { arrayBuffer },
     {
       convertImage: mammoth.images.inline((element) => {
         return element.read('base64').then((imageBuffer) => {
           // Сохраняем в очередь для загрузки на бэкенд
           return { src: `data:${element.contentType};base64,${imageBuffer}` };
         });
       }),
     }
   );
   const cleanHtml = result.value;
   ```
3. **Оптимизация картинок:**
   - Извлечь base64-изображения из HTML, сконвертировать в `Blob`, отправить на `POST /api/v1/upload/batch`.
   - Заменить base64-источники в HTML на постоянные URL, полученные от сервера.
4. **Обновление состояния Puck:**
   - Вызвать `dispatch({ type: 'setData', ... })` для вставки сконвертированного HTML в свойство `html` блока `WordText`.
