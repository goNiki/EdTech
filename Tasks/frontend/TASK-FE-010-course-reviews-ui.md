# 🎨 [FE-010] Отображение рейтинга со звездами и форма отзыва на лендинге курса

> **Приоритет:** Medium (P2)  
> **Связанные задачи:** BE-010, QA-010  
> **Компоненты / Страницы:** `frontend/src/components/CourseCard.tsx`, `frontend/src/app/courses/[slug]/page.tsx`, `frontend/src/app/dashboard/courses/[id]/page.tsx`

## 🎯 Цель задачи
Визуализировать социальное доказательство качества курсов: выводить желтые звезды рейтинга и счетчик отзывов на карточках витрины, добавить секцию отзывов с комментариями студентов на страницу лендинга курса и форму добавления отзыва в учебном кабинете студента при достижении прогресса 30%.

## 🖥 Пользовательский интерфейс (UI / UX)
- **Карточка курса (`CourseCard.tsx`):**
  - Рядом с количеством уроков и студентов выводить плашку: `★ 4.9 (128 отзывов)`.
- **Страница курса (`courses/[slug]`):**
  - Секция «Отзывы студентов»:
    - Общий средний балл с гистограммой распределения (5★, 4★, 3★...).
    - Список отзывов: аватар, имя студента, дата, рейтинг в виде 5 звезд, текст комментария.
- **Учебный кабинет (`dashboard/courses/[id]`):**
  - Если прогресс >= 30%, отображать карточку-призыв:  
    *«Вам нравится курс? Оцените обучение и поделитесь впечатлениями!»*
  - Интерактивный компонент 5 звезд (hover-эффект) + текстовое поле.

## 🔌 Интеграция с API (Контракт с Бэкендом)
- Загрузка отзывов: `GET /api/v1/courses/${courseId}/reviews`
- Отправка отзыва:
  ```typescript
  await api.post(`/courses/${courseId}/reviews`, {
    rating: starsCount,
    comment: reviewText.trim(),
  });
  ```

## ✅ Критерии приёмки (Definition of Done)
- [x] Рейтинг на карточках и лендинге отображается корректно.
- [x] Студент может легко выставить оценку звездами и оставить текстовый комментарий.
- [x] Форма отзыва скрыта или заблокирована до достижения порога 30% прогресса.
