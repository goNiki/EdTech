# 🎨 [FE-008] «Опасная зона» и удаление курса в настройках преподавателя

> **Статус:** ✅ Completed  
> **Приоритет:** High (P1)  
> **Связанные задачи:** BE-008, QA-008  
> **Компоненты / Страницы:** `frontend/src/app/teacher/courses/[id]/settings/page.tsx`

## 🎯 Цель задачи
В настройках курса преподавателя отсутствует блок опасных действий (Danger Zone). Автор не может удалить ошибочно созданный или неактуальный курс через интерфейс. Задача — добавить секцию «Опасная зона» с защитой от случайного удаления через подтверждение ввода названия курса.

## 🖥 Пользовательский интерфейс (UI / UX)
- В нижней части страницы `/teacher/courses/[id]/settings` добавлен блок «Опасная зона» с предупреждающей индикацией:
  - Описание: *«Удаление курса необратимо. Курс исчезнет из каталога, а студенты потеряют доступ к материалам.»*
  - Кнопка: «Удалить этот курс» (красный контур, hover-заливка).
- **Модальное окно подтверждения (Delete Confirmation Modal):**
  - Заголовок: *«Вы абсолютно уверены?»*
  - Требование ввести название курса для подтверждения:
    - *«Пожалуйста, введите название курса **«{courseTitle}»** для подтверждения удаления:»*
    - Инпут для ввода названия с автофокусом.
    - Кнопка «Я понимаю последствия, удалить курс» активна только при точном совпадении введенной строки с названием.
  - При успехе — показ уведомления и редирект в список курсов автора `/teacher/courses`.

## 🔌 Интеграция с API (Контракт с Бэкендом)
- Запрос: `DELETE /api/v1/courses/${id}`
- Обработка ошибок: показ понятного сообщения 403, если пользователь не является владельцем курса.

## ✅ Критерии приёмки (Definition of Done)
- [x] Автор курса может удалить свой курс из настроек.
- [x] Случайный клик предотвращается требованием текстового подтверждения.
- [x] После удаления происходит редирект на `/teacher/courses`, курс больше не отображается в списке.
