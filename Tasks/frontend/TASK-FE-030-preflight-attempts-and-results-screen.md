# 🎨 [FE-030] Pre-flight экран истории попыток, защита прогресса и экран итоговых результатов (Result Screen)

> **Приоритет:** High (P1)  
> **Связанные задачи:** BE-029, QA-030  
> **Компоненты / Страницы:**  
> - `frontend/src/components/player/QuizPreflightScreen.tsx`  
> - `frontend/src/components/player/QuizResultScreen.tsx`  
> - `frontend/src/app/lessons/[id]/page.tsx`

---

## 🎯 Цель задачи
1. **Pre-flight экран перед стартом теста:**  
   Если студент уже сдавал этот тест ранее, при открытии урока показывать вводный экран с историей:
   *«Вы уже проходили тестирование 2 раза. Ваш высший балл: 90% (Зачтено). Осталось попыток: 1 из 3»*.
   Студент должен явно подтвердить желание начать новую попытку кнопкой `[Начать попытку N]` либо спокойно вернуться к программе курса, не боясь потерять заработанную оценку.
2. **Экран результатов (Result Screen) после завершения:**  
   По завершении теста выводить мотивирующий экран с инфографикой:
   - Процент и баллы (напр. **85% — 17/20 баллов**).
   - Статус прохождения: **«Тест успешно сдан! 🎉»** или **«Порог не пройден (порог 70%)»**.
   - Время, затраченное на тест.
   - Главные действия:
     - Крупная кнопка `[Следующий урок: Название ->]` (быстрый переход к следующему уроку курса).
     - Кнопка `[Пройти заново 🔄 (Осталось X попыток)]` (если лимит не исчерпан).
     - Ссылка `[Вернуться к списку уроков курса]`.

## 🔌 Интеграция с API (Контракт BE-029)
1. При загрузке урока `/lessons/{id}`:
   - Вызывать `GET /api/v1/lessons/{id}/attempts/summary`.
   - Если `total_attempts_made > 0` и нет активной начатой попытки — показывать `QuizPreflightScreen`.
2. При клике `[Начать попытку]`:
   - Вызывать `POST /api/v1/lessons/{id}/attempts/start`.
   - Получить `attempt_id` и переключить экран в `QuizStepperPlayer`.
3. По завершении теста:
   - Переключить экран в `QuizResultScreen` с полученными серверными метриками.
   - Запросить ID следующего урока из структуры курса (`/courses/{course_id}/structure`) для кнопки перехода.

## ✅ Критерии приёмки (Definition of Done)
- [x] Повторный вход в пройденный тест открывает Pre-flight экран с показом лучшего балла.
- [x] Оценка и статус прохождения урока не сбрасываются при открытии страницы.
- [x] После окончания теста отображается информативный экран результатов с кнопкой перехода к следующему уроку.
- [x] Кнопка повторной попытки доступна только при наличии неиспользованных попыток.
- [x] Переход к следующему уроку корректно загружает следующий модуль/урок курса.
