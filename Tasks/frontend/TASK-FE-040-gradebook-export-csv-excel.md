# 🎨 [FE-040] Кнопка выгрузки ведомости успеваемости в Excel / CSV в кабинете преподавателя

> **Приоритет:** High (P1)  
> **Связанные задачи:** BE-037, QA-040  
> **Компоненты / Страницы:** `frontend/src/app/teacher/courses/[id]/curriculum/page.tsx`, `frontend/src/components/teacher/StudentsTable.tsx`  
> **Документация модуля:** [frontend/src/components/README.md](../../frontend/src/components/README.md)

---

## 🎯 Цель задачи
Предоставить преподавателю инструмент быстрой выгрузки ведомости студентов курса в Excel / CSV непосредственно со вкладки «Студенты» курса ([`/teacher/courses/[id]/curriculum?tab=students`](../../frontend/src/app/teacher/courses/%5Bid%5D/curriculum/page.tsx)).

---

## 🖥 Пользовательский интерфейс (UI / UX)
- В шапке таблицы студентов (рядом со строкой поиска и кнопкой «+ Зачислить студента») разместить кнопку:
  - **«Выгрузить ведомость (CSV / Excel)»** с иконкой `Download` или `FileSpreadsheet`.
- При нажатии:
  - Кнопка переходит в состояние загрузки со спиннером (`Loader2 animate-spin`) и текстом «Формирование отчета...».
  - Инициируется скачивание файла через защищенный запрос с Bearer-токеном (через `api.get('/courses/' + id + '/analytics/export?format=csv', { responseType: 'blob' })`).
  - Браузер инициирует стандартное сохранение файла (`gradebook_course_[id]_[date].csv`).
  - Всплывает успешный тост: «Ведомость курса успешно выгружена».

---

## ✅ Критерии приёмки (Definition of Done)
- [x] Кнопка доступна преподавателю и администратору на вкладке студентов курса.
- [x] Файл скачивается с корректным расширением `.csv` и понятным именем с датой выгрузки.
- [x] Ошибки скачивания (например, сбой сети) обрабатываются с отображением тоста с ошибкой без зависания интерфейса.
