# 🎨 [FE-006] Форма смены пароля и безопасность аккаунта в настройках профиля

> **Приоритет:** Medium (P1)  
> **Связанные задачи:** BE-006, QA-006  
> **Компоненты / Страницы:** `frontend/src/app/dashboard/settings/page.tsx`

## 🎯 Цель задачи
На бэкенде существует готовый эндпоинт `POST /api/v1/auth/change-password`, но в клиентском интерфейсе в настройках профиля нет полей для смены пароля. Необходимо добавить раздел «Безопасность» с формой обновления пароля, переключателями видимости («глаз») и валидацией совпадения.

## 🖥 Пользовательский интерфейс (UI / UX)
- В `dashboard/settings/page.tsx` добавить третью вкладку в таб-бар:  
  `[ Профиль пользователя ] [ Безопасность и пароль ] [ Внешний вид ]`
- **Содержимое вкладки «Безопасность»:**
  - Карточка смены пароля:
    - Поле «Текущий пароль» (с кнопкой показать/скрыть).
    - Поле «Новый пароль» (индикатор надежности пароля: длина, спецсимволы).
    - Поле «Повторите новый пароль».
  - Кнопка «Обновить пароль» (с блокировкой при несовпадении и спиннером загрузки).
  - Предупреждение: *«После смены пароля вам потребуется войти в аккаунт заново на других устройствах.»*
  - Успешное состояние: зеленый тост об успешном обновлении и очистка полей формы.

## 🔌 Интеграция с API (Контракт с Бэкендом)
- Запрос:
  ```typescript
  await api.post('/auth/change-password', {
    old_password: currentPassword,
    new_password: newPassword,
  });
  ```
- Клиентская валидация:
  - Проверка `newPassword.length >= 8`.
  - Проверка `newPassword === confirmPassword`.
  - Запрет отправки `newPassword === currentPassword`.

## ✅ Критерии приёмки (Definition of Done)
- [x] Пользователь может сменить пароль из личного кабинета.
- [x] Ошибки неверного текущего пароля выводятся понятным сообщением.
- [x] Поля формы очищаются после успешного сохранения.
