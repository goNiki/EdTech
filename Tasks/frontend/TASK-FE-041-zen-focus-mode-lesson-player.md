## 🎯 Цель задачи
Снизить когнитивную нагрузку и предоставить студентам режим максимального погружения в учебный процесс (чтение объемных лекций, просмотр презентаций и решение экзаменационных тестов без отвлекающих визуальных шумов).

Внедрить **Режим концентрации (Focus / Zen Mode)**:
1. Кнопка включения режима в верхней панели плеера (иконка `Maximize2` / `Minimize2`).
2. Поддержка горячей клавиши `F` (Focus) для быстрого переключения и `Esc` для выхода.
3. При активации:
   - Скрываются общие навигационные панели и служебные бейджи.
   - Ширина контейнера контента плавно оптимизируется под идеальную типографическую колонку чтения (680–800px) либо под полный экран для презентаций.
   - В правом верхнем углу остается минималистичная полупрозрачная плавающая кнопка выхода из режима.

---

## 🖥 Пользовательский интерфейс (UI / UX)
- **Тумблер в шапке:** Иконка `Maximize2` с подсказкой «Режим фокуса (F)».
- **Поведение интерфейса:**
  - Плавная CSS-анимация перехода (opacity, padding).
  - При активном Zen Mode фон страницы переключается в мягкий нейтральный оттенок (`bg-slate-50 dark:bg-slate-950`).
  - Плавающий индикатор прогресса (тонкая полоска вверху экрана `h-1 bg-indigo-600`), показывающая процент прокрутки или шаг квиза.
- **Горячие клавиши:** слушатель события `keydown`:
  - `F` или `f` (если фокус не находится в текстовом поле ввода) ➔ переключение режима.
  - `Escape` ➔ принудительный выход в стандартный режим.

## ✅ Критерии приёмки (Definition of Done)
- [x] Режим фокуса активируется и деактивируется по клику и по клавишам `F` / `Esc`.
- [x] При вводе ответа в текстовое поле эссе нажатие буквы `F` не переключает режим.
- [x] В режиме фокуса весь интерактив уроков и тестов функционирует без ограничений.
