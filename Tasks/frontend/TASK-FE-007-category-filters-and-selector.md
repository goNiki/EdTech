# 🎨 [FE-007] Фильтрация курсов по категориям на витрине и селектор в мастере курса

> **Статус:** ✅ Completed  
> **Приоритет:** Medium (P1)  
> **Связанные задачи:** BE-007, QA-007  
> **Компоненты / Страницы:** `frontend/src/app/courses/page.tsx`, `frontend/src/app/teacher/courses/new/page.tsx`, `frontend/src/app/teacher/courses/[id]/settings/page.tsx`, `frontend/src/lib/categories.ts`

## 🎯 Цель задачи
Интегрировать категории курсов в пользовательский интерфейс: вывести горизонтальный скролл чипсов (тегов) категорий или выпадающий список в каталоге курсов для быстрой фильтрации, а в формах создания и редактирования курса преподавателем — подтягивать реальный список категорий с сервера вместо захардкоженных опций.

## 🖥 Пользовательский интерфейс (UI / UX)
- **Каталог курсов (`/courses`):**
  - Под строкой поиска расположен горизонтальный скролл чипсов категорий с иконками тегов и счетчиками курсов:  
    `[ Все категории ] [ Программирование ] [ Веб-разработка ] [ Data Science ] [ Дизайн ] [ Бизнес ]`
  - Активная категория подсвечивается индиго-фоном с белым текстом (`bg-indigo-600 text-white shadow-md`).
  - При клике на категорию параметр `category_id` передается в запрос и синхронизируется в URL query (`?category_id=...`), результаты мгновенно фильтруются с дебаунсингом.
  - На каждой карточке курса выводится бейдж категории.
- **Мастер курса (`teacher/courses/new`) и настройки курса (`teacher/courses/[id]/settings`):**
  - Интегрирован динамический выпадающий список категорий, загружаемый через `fetchCategories()` (`GET /api/v1/categories` с fallback на `DEFAULT_CATEGORIES`).
  - Идентификатор категории (`category_id`) отправляется в `POST /courses` и `PATCH /courses/{id}`.

## 🔌 Интеграция с API (Контракт с Бэкендом)
- Загрузка категорий: `GET /api/v1/categories` (модуль `frontend/src/lib/categories.ts`)
- Передача фильтра в каталог: `GET /api/v1/courses?category_id=${selectedCategoryId}`

- [x] Фильтрация по клику на категорию моментально обновляет карточки курсов.
- [x] При создании курса автор выбирает категорию из актуального справочника.
