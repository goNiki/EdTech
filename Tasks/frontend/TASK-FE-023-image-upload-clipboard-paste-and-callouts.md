# TASK-FE-023: Загрузка картинок с диска, вставка из буфера обмена (Ctrl+V), интерактивные Callout-блоки и импорт документов в Canvas

## 📋 Описание проблемы
1. **Вставка картинок:** Ранее картинки можно было вставлять только по внешней ссылке URL. Пользователь хочет загружать файлы прямо с диска, перетаскивать их (drag & drop) и вставлять скриншоты напрямую из буфера обмена (Ctrl+V).
2. **Уникальные смысловые блоки (Callouts):** Требуются готовые варианты цветных плашек («Совет», «Важно», «Заметка», «Цель») с иконками и акцентным оформлением.
3. **Импорт Word / Markdown в Canvas-блок:** В `RichTextCanvasEditor` отсутствовала кнопка прямого импорта `.docx` и `.md`, которая была только в `RichTextWordEditor`.

## 🎯 Цели и задачи
- [x] Добавить в модальное окно вставки изображений вкладки: «Загрузка с устройства» (выбор файла / drag & drop) и «По ссылке».
- [x] Интегрировать загрузку изображений через API `/upload` (категория `lesson_media`) с безопасным fallback на оптимизированный data-URL при локальной разработке.
- [x] Добавить обработчик `paste` (Ctrl+V) на редактируемые области: при наличии в буфере изображений перехватывать их и автоматически вставлять `<figure><img ... /></figure>`.
- [x] Добавить меню вставки Callout-блоков с выбором типа: 💡 Совет, ⚠️ Важно, 📝 Заметка, 🎯 Цель.
- [x] Добавить в `RichTextCanvasEditor` кнопку «Импорт .docx / .md» и обработку drag & drop файлов документов, аналогично блоку статьи лекции.
- [x] Протестировать функционал в браузере с помощью Puppeteer.

   - Выпадающее меню Callout содержит все 4 типа (💡 Совет, ⚠️ Важно, 📝 Заметка, 🎯 Цель), их вставка создает стилизованные блоки с цветными границами и иконками.
