# TASK-FE-021: Сохранение вёрстки, выравнивания, подчёркиваний и таблиц при импорте Microsoft Word (.docx)

## 📋 Описание проблемы
При импорте документов Microsoft Word (`.docx`) через библиотеку `mammoth`:
1. **Потеря выравнивания:** Mammoth по умолчанию парсит теги `w:jc` (выравнивание абзаца: по центру, по правому краю, по ширине) во внутренний AST, но не выводит никаких классов или стилей в сгенерированный HTML, сбрасывая весь текст по левому краю.
2. **Потеря подчёркиваний (`<u>`):** Mammoth по умолчанию отбрасывает свойство underline (`w:u`), если в `styleMap` явно не прописано `u => u`.
3. **Потеря зачёркиваний (`<s>`):** Без правила `strike => s` зачёркнутый текст рендерится как обычный.
4. **Потеря стилей из-за агрессивной очистки `mso-*`:** Регулярное выражение `style="[^"]*mso-[^"]*"` удаляло весь атрибут `style="..."`, даже если там находились полезные CSS-свойства (`text-align: center`, `font-size`, `font-weight`, `color`).
5. **Жёсткое переопределение таблиц:** Замена `<table` на `<table ... text-left>` принудительно перебивала выравнивание контента внутри ячеек таблиц.

- [x] Исправить `cleanWordHtml`: удалять только конкретные декларации `mso-[^;:"']+(;)?`, не затрагивая валидные CSS-правила.
- [x] Добавить в `cleanWordHtml` автоматическую расстановку inline-стилей `style="text-align: center;"` (и right, justify) для всех элементов с классами `text-center`, `text-right`, `text-justify` для гарантированного рендера в любых условиях.
