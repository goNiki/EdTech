# 🎨 [FE-012] Виджет уведомлений с колокольчиком и выпадающим списком в шапке

> **Приоритет:** Low (P2)  
> **Связанные задачи:** BE-012, QA-012  
> **Компоненты / Страницы:** `frontend/src/components/layout/TopNavbar.tsx`

## 🎯 Цель задачи
Добавить в верхнюю навигационную панель `TopNavbar` иконку колокольчика со счетчиком непрочитанных событий, всплывающим окном (Popover) со списком последних уведомлений и возможностью перехода к проверенным заданиям в один клик.

## 🖥 Пользовательский интерфейс (UI / UX)
- **Иконка колокольчика (`TopNavbar.tsx`):**
  - Иконка `Bell` (Lucide Icons) рядом с переключателем темы.
  - Красный бейдж со счетчиком непрочитанных событий (например, `3`). Если `unread_count === 0`, бейдж скрывается.
- **Выпадающее меню (Notifications Dropdown / Popover):**
  - Шапка: заголовок *«Уведомления»* и ссылка *«Прочитать все»*.
  - Список уведомлений (скролл до 5 элементов):
    - Иконка типа события (зеленая галочка для проверенного ДЗ, синяя книга для нового урока).
    - Заголовок и краткий текст сообщения.
    - Время получения (например, «15 минут назад»).
    - Непрочитанные элементы подсвечиваются мягким синим фоном.
  - При клике на уведомление:
    - Отправка запроса на отметку о прочтении.
    - Переход по ссылке события (`link_url`).
  - Empty-state: иконка колокольчика и надпись *«Новых уведомлений пока нет»*.

## 🔌 Интеграция с API (Контракт с Бэкендом)
- Запрос списка: `GET /api/v1/notifications` (периодический опрос раз в 60 секунд или при фокусе окна).
- Отметка о прочтении: `PATCH /api/v1/notifications/${id}/read`
- Отметка всех: `POST /api/v1/notifications/read-all`

## ✅ Критерии приёмки (Definition of Done)

- [x] Клик по уведомлению перенаправляет на нужный урок/задание и снимает статус непрочитанного.
- [x] Кнопка «Прочитать все» сбрасывает счетчик в ноль.
