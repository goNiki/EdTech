# 🛠 [BE-037] API экспорта ведомости успеваемости курса в CSV / XLSX

> **Приоритет:** High (P1)  
> **Связанные задачи:** FE-040, QA-040  
> **Целевой модуль:** `internal/interfaces/handlers/analytics/`, `internal/service/analytics/`, `internal/repository/analytics/`  
> **Документация модуля:** [internal/service/analytics/README.md](../../internal/service/analytics/README.md)

---

## 🎯 Цель задачи
Предоставить преподавателю возможность сформировать и скачать официальную ведомость успеваемости студентов курса в формате CSV (с кодировкой UTF-8 BOM для безупречного открытия в MS Excel):
1. Идентификатор студента (`ID`).
2. ФИО и Email студента.
3. Дата зачисления на курс (`Enrolled Date`).
4. Прогресс прохождения курса в процентах (`Progress %`).
5. Количество пройденных уроков / всего уроков (`Completed Lessons / Total`).
6. Средний балл за проверочные тесты (`Average Quiz Score %`).
7. Количество сданных и оцененных домашних заданий.
8. Статус сертификата (Выдан / В процессе).

---

## 🔍 Текущее состояние кода
- В `internal/service/analytics/` реализован метод `GetCourseStudentsWithProgress`, возвращающий JSON со списком учащихся. Отдельного эндпоинта генерации потокового CSV-файла с заголовками скачивания нет.

---

## 📝 Технические требования к реализации

### 1. HTTP Endpoint
`GET /api/v1/courses/{id}/analytics/export?format=csv`
* **Авторизация:** Bearer JWT (преподаватель, создатель курса или администратор).
* **Заголовки ответа:**
  ```http
  Content-Type: text/csv; charset=utf-8
  Content-Disposition: attachment; filename="gradebook_course_13_2026-10-04.csv"
  Cache-Control: no-cache
  ```
* **Кодировка:** обязательно передавать UTF-8 Byte Order Mark (`\xEF\xBB\xBF`) первым байтом потока, чтобы кириллические имена студентов корректно отображались в русской версии Microsoft Excel.

### 2. Структура CSV-файла
```csv
ID;Студент;Email;Дата записи;Прогресс (%);Пройдено уроков;Всего уроков;Средний балл (%);Статус;Сертификат
101;Иван Иванов;ivan@mail.ru;01.10.2026;100%;12;12;94%;Завершен;Выдан (EDL-2026-AB12CD34)
102;Анна Смирнова;anna@mail.ru;02.10.2026;65%;8;12;88%;В процессе;—
```
Разделитель колонок: точка с запятой (`;`), так как запятые часто встречаются в именах и дробных процентах в российской локали.

### 3. Бизнес-логика (Service Layer)
- Проверка прав: преподаватель должен быть автором курса (`courses.created_by == userID`) либо администратором.
- Выгрузка данных всех студентов через оптимизированный CTE-запрос.
- Потоковая генерация строк через `encoding/csv` с `Comma = ';'`.
