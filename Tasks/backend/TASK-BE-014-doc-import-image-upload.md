# 🛠 [BE-014] Пакетная загрузка встроенных изображений из Word-документов

> **Статус:** Completed  
> **Приоритет:** Medium (P1)  
> **Связанные задачи:** FE-014, QA-014  
> **Целевой модуль:** `internal/interfaces/handlers/upload/`, `internal/service/upload/`  
> **Документация модуля:** [PROJECT_MAP.md](../../PROJECT_MAP.md)

## 🎯 Цель задачи
При импорте файлов Word (`.docx`) на клиенте парсер извлекает встроенные в документ изображения (графики, диаграммы, скриншоты). Если сохранять их в виде raw `data:image/png;base64,...` внутри поля `lesson.content`, размер JSON урока может раздуться до десятков мегабайт, что приведет к деградации производительности БД и длительной загрузке у студентов. Задача — предоставить эндпоинт пакетной загрузки изображений из импортируемого документа, сохраняющий их в хранилище и возвращающий постоянные веб-ссылки.

## 🔍 Текущее состояние кода
- В рамках задачи `TASK-BE-002` создается базовый эндпоинт `POST /api/v1/upload`.
- Требуется расширить его или добавить поддержку пакетной загрузки нескольких файлов в одном multipart-запросе (`files[]`), чтобы клиент не отправлял 30 отдельных HTTP-запросов для одного Word-документа.

## 📝 Технические требования к реализации
1. **API / Endpoint:**
   - `POST /api/v1/upload/batch`
   - Content-Type: `multipart/form-data`
   - Headers: `Authorization: Bearer <token>`
   - Form Fields:
     - `files[]` (массив бинарных файлов картинок)
     - `category`: `lesson_media`
   - Response DTO (201 Created):
     ```json
     {
       "uploaded": [
         {
           "original_name": "image1.png",
           "file_url": "http://localhost:8082/static/uploads/lesson_media/2026/10/uuid1.png",
           "size_bytes": 145020
         },
         {
           "original_name": "image2.jpg",
           "file_url": "http://localhost:8082/static/uploads/lesson_media/2026/10/uuid2.jpg",
           "size_bytes": 98310
         }
       ]
     }
     ```

2. **Бизнес-логика (Service Layer):**
   - Лимит на пакет: максимум 50 изображений за раз, общий размер пакета до 50 МБ.
   - Валидация каждого файла: только `image/jpeg`, `image/png`, `image/webp`, `image/gif`.
   - Асинхронное/параллельное сохранение файлов через горутины в локальное хранилище или S3.

3. **Побочные эффекты:**
   - Логирование количества успешно загруженных файлов в одном пакете.

## ✅ Критерии приёмки (Definition of Done)
- [x] Эндпоинт `POST /api/v1/upload/batch` принимает массив изображений и возвращает массив публичных URL.
- [x] Невалидные файлы в пакете отклоняются с понятным сообщением об ошибке.
- [x] Изображения доступны по прямым ссылкам со статического шлюза `/static/*`.
