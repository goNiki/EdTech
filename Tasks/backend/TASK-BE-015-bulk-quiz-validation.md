# 🛠 [BE-015] Валидация структуры и сохранение пакетно импортированных тестов

> **Статус:** Completed  
> **Приоритет:** High (P0)  
> **Связанные задачи:** FE-015, QA-015  
> **Целевой модуль:** `internal/interfaces/handlers/lesson/`, `internal/service/lesson/`  
> **Документация модуля:** [internal/service/lesson/FUNCTIONAL_SPEC.md](../../internal/service/lesson/FUNCTIONAL_SPEC.md)

## 🎯 Цель задачи
Обеспечить серверную стабильность и валидацию структуры при пакетном добавлении большого количества интерактивных тестов (от 20 до 100 квизов за один раз) в поле `lesson.content`. Проверить, что размер JSON-поля в базе данных PostgreSQL (`lessons.content TEXT`) поддерживает крупные наборы заданий, а схема данных блоков Puck валидируется на отсутствие циклических ссылок и поврежденных символов.

## 🔍 Текущее состояние кода
- В `internal/interfaces/handlers/lesson/handler.go` эндпоинт `PATCH /api/v1/lessons/{id}` принимает `req.Content` как сырую строку `*string`.
- В `internal/service/lesson/updateLesson.go` контент сохраняется в БД без дополнительной проверки структуры JSON.
- При массовом импорте (100 тестов) размер контента урока может достигать сотен килобайт.

## 📝 Технические требования к реализации
1. **API / Handlers:**
   - В `UpdateLesson`: при передаче `content` проверять, что это валидный JSON (`json.Valid([]byte(*req.Content))`).
   - Если передан некорректный JSON — возвращать 400 Bad Request (`errorsAPP.ErrValidationFailed`).
   - Установить разумный верхний лимит на размер тела запроса (например, 5 МБ для контента урока).

2. **Бизнес-логика (Service Layer):**
   - Проверить, что блоки в JSON содержат обязательные поля схемы Puck (`type`, `props.id`).
   - При обнаружении блоков тестов (`SingleChoiceBlock`, `MultipleChoiceBlock`, `MatchingBlock`) гарантировать, что уникальные идентификаторы блоков (`id`) не дублируются внутри одного урока.

3. **База данных / Хранилище:**
   - Проверить тип колонки в миграции `migrators/20250912230053_create_table_lesson.sql`: колонка `content` имеет тип `TEXT`. При необходимости добавить миграцию для конвертации в `JSONB` для возможности серверного индексирования вопросов и поиска по тестам.

## ✅ Критерии приёмки (Definition of Done)
- [x] Урок с 50+ импортированными тестами сохраняется через `PATCH /lessons/{id}` без ошибок таймаута и переполнения.
- [x] Передача сломанного JSON отклоняется с ошибкой 400.
- [x] Дубликаты ID блоков внутри урока исключены.
