## 📋 Тест-кейсы

### Test Case 1: Ввод значения больше максимального балла (Over maximum)
1. Авторизоваться как преподаватель (`nikit@mail.ru` / `Nikita9379992`).
2. Открыть очередь проверки ДЗ: `http://localhost:3000/teacher/grading`.
3. Открыть карточку задания с `max_points = 25`.
4. Ввести в поле балла значение `30`.
5. **Ожидаемый результат:**
   - Поле ввода подсвечивается красной рамкой `border-rose-500`.
   - Под полем отображается текст: `Балл не может превышать 25`.
   - В правом верхнем углу лейбла выводится бейдж `(!) Максимум 25 б.`.
   - Кнопка «Утвердить оценку» заблокирована (`disabled`).

### Test Case 2: Ввод отрицательного значения (Negative points)
1. Ввести в поле балла значение `-5`.
2. **Ожидаемый результат:**
   - Поле ввода подсвечивается красным цветом.
   - Под полем выводится сообщение `Балл не может быть отрицательным`.
   - Кнопка «Утвердить оценку» заблокирована.

### Test Case 3: Ввод корректного значения в пределах [0, max_points]
1. Ввести в поле значение `20`.
2. **Ожидаемый результат:**
   - Рамка возвращается в нормальное состояние.
   - Предупреждения исчезают.
   - Кнопка «Утвердить оценку» активна (зеленая).
   - При клике оценка успешно сохраняется и отправляется на сервер.
