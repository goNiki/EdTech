3. **Шаг 3 (Расчет позиции):** Вычисляет `position = GetMaxPositionByCourseID + 1`.
4. **Шаг 4 (Сохранение):** Выполняет `INSERT INTO lessons` и возвращает присвоенный ID.

### ⚡ Функция: `UpdateLesson(ctx, userID, lesson)`

* **Файл и строки:** [`updateLesson.go#L12-L79`](file:///c:/Users/gogol/OneDrive/Desktop/EdTech/internal/service/lesson/updateLesson.go#L12-L79)
* **Бизнес-назначение:** Изменение параметров урока и сохранение структуры контента Puck Editor (включая крупные наборы импортированных интерактивных тестов).
* **Связанная фича:** *Редактирование урока*

#### 📥 Входные параметры
| Параметр | Тип | Обязателен | Бизнес-смысл и ограничения |
|---|---|:---:|---|
| `userID` | `int64` | Да | Идентификатор преподавателя/автора, инициирующего обновление |
| `lesson.ID` | `int64` | Да | Идентификатор обновляемого урока |
| `lesson.Title` | `string` | Нет | Новое название урока (1–255 символов) |
| `lesson.Description` | `string` | Нет | Новое описание урока |
| `lesson.Content` | `string` | Нет | Puck JSON контент урока. Должен быть валидным JSON (до 5 МБ) со схемой блоков и уникальными `props.id` |
| `lesson.Type` | `string` | Нет | Тип урока (`lecture`, `exercise`, `practice`, `quiz`, `assignment`, `homework`) |

#### 🔄 Пошаговый алгоритм работы
1. **Шаг 1 (Проверка существования):** Ищет существующий урок в `lessonrepo.GetLessonByID`. При отсутствии возвращает `ErrNotFoundLesson`.
2. **Шаг 2 (RBAC авторизация):** Проверяет права пользователя на редактирование курса (`accessService.CanEditCourse`). Если доступ запрещен — возвращает `ErrForbidden`.
3. **Шаг 3 (Слияние полей):** Выполняет частичное обновление (partial merge): незаполненные поля сохраняют текущие значения из БД.
4. **Шаг 4 (Валидация домена и Puck JSON):** Вызывает `lesson.Validate()`:
   - Проверяет обязательные метаданные (`Title`, `Description`, `CourseID`).
   - Если передан `Content`, вызывает `ValidateLessonContent(content)`:
     - Проверяет валидность JSON-синтаксиса.
     - Проверяет структуру списка блоков (корневой объект с полем `content` или массив).
     - Проверяет наличие обязательного поля `type` у каждого блока.
     - Для всех интерактивных квиз-блоков гарантирует наличие идентификатора `props.id`.
     - Защищает от дублирования идентификаторов блоков внутри одного урока (`seenIDs`).
5. **Шаг 5 (Сохранение в БД):** Вызывает `lessonrepo.UpdateLesson(ctx, lesson)` для сохранения текстового JSON в PostgreSQL.

#### ⚠️ Побочные эффекты (Side Effects)
* **База данных:** Мутирует строку урока в таблице `lessons`, обновляя `updated_at = NOW()`.

#### 📤 Результат и ошибки
* **Успешный результат:** `nil` (код 200 OK).
* **Возможные ошибки:**
  * `ErrNotFoundLesson` (404) — урок не найден.
  * `ErrForbidden` (403) — нет прав на редактирование курса.
  * `ErrLessonValidation` (400) — некорректный Puck JSON, дубликаты ID блоков или отсутствующий `type`.
  * `ErrFileTooLarge` (400) — превышение максимального лимита размера тела запроса (5 МБ).
