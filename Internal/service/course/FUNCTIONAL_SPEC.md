## 🎯 Каталог бизнес-фич модуля
| Фича | Описание возможности | Обеспечивающие функции |
|---|---|---|
| **Создание курса** | Создание черновика курса с транзакционным присвоением роли создателя (`creator`) | `CreateCourse()` |

### ⚡ Функция: `CreateCourse(ctx, course)`

* **Файл и строки:** [`create.go#L13-L48`](file:///c:/Users/gogol/OneDrive/Desktop/EdTech/internal/service/course/create.go#L13-L48)
* **Бизнес-назначение:** Инициализация нового образовательного курса преподавателем.
* **Связанная фича:** *Создание курса*

#### 📥 Входные параметры
| Параметр | Тип | Обязателен | Бизнес-смысл и ограничения |
|---|---|:---:|---|
| `course.Title` | `string` | Да | Название курса (не пустое, макс 255) |
| `course.Slug` | `string` | Да | Человекочитаемый уникальный идентификатор для URL |
| `course.CreatedBy` | `int64` | Да | ID преподавателя-создателя курса |
| `course.Visibility` | `string` | Да | `public` (каталог) или `private` (по приглашению) |

#### 🔄 Пошаговый алгоритм работы
1. **Шаг 1 (Нормализация слага):** Преобразует слаг к безопасному нижнему регистру `[a-z0-9-]` через `utils.NormalizeSlug(course.Slug)`.
2. **Шаг 2 (Валидация):** Проверяет корректность полей через `course.Validate()`.
3. **Шаг 3 (Присвоение начального статуса):** Курс принудительно создается в статусе `draft` (`domain.StatusDraft`).
4. **Шаг 4 (Транзакционное создание):** В рамках одной транзакции:
   - Проверяет уникальность слага через `resolveUniqueSlug` (`courseRepo.ExistsBySlug`); при обнаружении коллизии автоматически добавляет числовой суффикс (`-1`, `-2`, ...).
   - Создает запись в таблице `courses`.
   - Автоматически создает запись в `users_courses` с ролью `creator` для создателя курса.
5. **Шаг 5 (Результат):** Возвращает созданную сущность с присвоенным `Id` и уникальным `Slug`.

#### ⚠️ Побочные эффекты (Side Effects)
* **База данных:** Создает строки в `courses` и `users_courses`. При коллизии слага автоматически присваивает разрешенный уникальный слаг.

### ⚡ Функция: `PublishCourse(ctx, userID, courseID)`

* **Файл и строки:** [`publish.go#L14-L48`](file:///c:/Users/gogol/OneDrive/Desktop/EdTech/internal/service/course/publish.go#L14-L48)
* **Бизнес-назначение:** Открытие курса для студентов и каталога с автоматической активацией материалов.
* **Связанная фича:** *Каскадная публикация*

#### 🔄 Пошаговый алгоритм работы
1. **Шаг 1 (Загрузка):** Запрашивает курс по `courseID`.
2. **Шаг 2 (Проверка прав):** Вызывает `accessService.CanPublishCourse(ctx, course, userID)` (автор или админ). Если нет прав ➔ `ErrForbidden`.
3. **Шаг 3 (Доменный переход):** Вызывает `course.Publish(time.Now())`, фиксируя дату публикации `published_at`.
4. **Шаг 4 (Каскадная транзакция):** В рамках единой транзакции:
   - Обновляет курс в `courses` со статусом `published`.
   - Переводит все связанные секции курса в статус `published` (`UpdateStatusByCourseID`).
   - Переводит все связанные уроки курса в статус `published` (`UpdateStatusByCourseID`).

### ⚡ Функция: `GetCourseStructure(ctx, courseID)`

* **Файл и строки:** [`getCourseStructure.go#L10-L65`](file:///c:/Users/gogol/OneDrive/Desktop/EdTech/internal/service/course/getCourseStructure.go#L10-L65)
* **Бизнес-назначение:** Предоставление полной учебной программы курса со всеми разделами и уроками для UI плеера/навигатора.
* **Связанная фича:** *Иерархическое дерево курса*

#### 🔄 Пошаговый алгоритм работы
1. Читает данные курса, список секций (`ListSectionsByCourseID`) и список уроков (`GetLessonsByCourseID`).
2. Группирует уроки по `section_id`.
3. Уроки с `section_id == nil` выделяет в отдельный список `UnsectionedLessons`.
4. Формирует структуру `domain.CourseStructure` со строгим сохранением порядка `position ASC`.

#### 💡 Подсказка для аналитика (Где менять логику?)
* *Скрыть неопубликованные уроки при запросе от студентов:* добавить фильтрацию по роли вызывающего пользователя в [`getCourseStructure.go#L35`](file:///c:/Users/gogol/OneDrive/Desktop/EdTech/internal/service/course/getCourseStructure.go#L35).
* *Ввести обязательную проверку наличия хотя бы одного урока перед публикацией:* раскомментировать проверку `c.TotalLessons > 0` в [`domain/course.go`](file:///c:/Users/gogol/OneDrive/Desktop/EdTech/internal/domain/course.go).
