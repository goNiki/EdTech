# 📦 Обработчик HTTP: `internal/interfaces/handlers/review`
> **Путь:** `internal/interfaces/handlers/review`  
> **Роль:** HTTP REST API для работы с отзывами и рейтингами курсов.

---

## 🎯 Назначение и ответственность
Прием HTTP-запросов, валидация входных данных, извлечение идентификаторов авторизованного пользователя из JWT контекста и отправка ответов клиентам.

---

## 🌐 Маршруты API
| Метод | Путь | Аутентификация | Описание |
|---|---|:---:|---|
| `GET` | `/api/v1/courses/{courseid}/reviews` | Опционально | Публичный пагинированный список отзывов и статистика |
| `POST` | `/api/v1/courses/{courseid}/reviews` | JWT | Добавление или обновление отзыва студента |
| `DELETE` | `/api/v1/courses/{courseid}/reviews` | JWT | Удаление своего отзыва |
| `GET` | `/api/v1/courses/{courseid}/reviews/my` | JWT | Получение своего отзыва на курс |
